Кто обрабатывает данные

Какие данные собираются

Только те, что посетитель вводит в форму записи по своей воле: имя родителя, номер телефона, возраст ребёнка, удобное время и комментарий. Иных данных сайт не запрашивает.

Дополнительно сохраняется название занятия, со страницы которого открыта форма, — чтобы администратор понимал, о чём идёт речь при звонке.

Зачем

Единственная цель — связаться по оставленной заявке и записать ребёнка на занятие. Для рассылок, рекламы и передачи третьим лицам данные не используются.
